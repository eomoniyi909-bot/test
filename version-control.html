🌿 Version Control

Tracking changes, building good habits

Git is one of the first "real developer" tools I started learning outside of just writing HTML, CSS, and JavaScript. It's less about the code itself and more about building a habit — saving progress properly, so nothing gets lost and every change has a history.

What I'm learning

  • Initializing a repository and tracking file changes with git init
  • Staging and committing changes with clear, descriptive messages
  • Understanding the difference between local changes and pushing to a remote repo
  • Using GitHub to store and share project code

A simple commit flow

$ git add .
$ git commit -m "Add search and sort to data table"
$ git push origin main
✓ Changes saved and pushed

Why it matters

Even on small solo projects, using Git means I can experiment freely — if something breaks, I can always go back to a version that worked. It's a habit I'm building now so it's second nature by the time I'm working on bigger projects.
