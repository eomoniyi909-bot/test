What I Learned Building My First Styled Table

My very first real project was a plain HTML table — just rows and columns with no styling at all. It didn't look like much, but it taught me the basics of how tables are structured in HTML: <table>, <tr>, <td>, and <th>.

The real learning started when I added CSS. Zebra striping (alternating row colors) taught me the :nth-child(even) selector. Hover highlights taught me how :hover works. Small details, but each one was a new concept.

Later, I went back and added a live search bar and sortable columns using JavaScript — which meant learning how to filter and sort arrays of data. What started as a simple styling exercise turned into my first real taste of front-end interactivity.
