Understanding Git: My First Week Using Version Control

For a while, "saving my work" meant duplicating a folder and renaming it project-final-v2. It worked, but it was messy. Learning Git changed that.

The first concept that clicked was a "commit" — a saved snapshot of my project at a specific point, with a message describing what changed. Instead of guessing which folder had the version I wanted, I could just look through my commit history.

Pushing to GitHub was the next step — learning that my code could live somewhere safe outside my laptop, and that I could look back at exactly how a project evolved over time. It's a small habit, but one I wish I'd started from my very first project.
