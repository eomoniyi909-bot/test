Building a Live GPA Calculator with JavaScript

My Grade Calculator project was the first time JavaScript actually felt useful to me instead of just abstract syntax. The goal was simple: let someone add courses, enter a grade and credit units, and instantly see their GPA.

The tricky part was the math logic — looping through every course row, multiplying credit units by grade points, adding them all up, then dividing by total units. Getting that formula right (and handling the case where no courses were entered yet) taught me a lot about writing careful, defensive code.

I also learned how to dynamically create new HTML elements with JavaScript — every time someone clicks "+ Add Course," a brand new row gets built and inserted into the page. That was my first real experience with DOM manipulation.
