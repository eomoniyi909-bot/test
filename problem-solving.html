🧩 Problem Solving

Breaking things down

This is the part of Computer Science that hooked me — taking a messy, confusing problem and breaking it into small pieces I can actually solve. Whether it's debugging a JavaScript function or figuring out how to sort a table, I like the process of thinking it through step by step.

How I approach it

  • Break the problem into the smallest possible steps before writing any code
  • Test one small piece at a time instead of writing everything at once
  • Read error messages carefully instead of guessing — they usually tell you exactly what's wrong
  • Search, read documentation, and ask questions when I'm stuck — not a weakness, just part of learning

Where this shows up

My Grade Calculator project is a good example — it needed logic to loop through every course, multiply units by grade points correctly, and handle cases where no courses were entered yet.
